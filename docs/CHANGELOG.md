# Changelog

## 0.1.0 — Milestones 0 and 1 foundation

* Initialized empty workspace with architecture and implementation documents.
* Added FastAPI, React/TypeScript/Tailwind/Lightweight Charts, Compose and Nginx.
* Added canonical models, explicit exchange sessions, provider protocol and Upstox
  OAuth, instrument/history/quote adapter and official V3 protobuf decoding.
* Added migrations, idempotent candle storage, corrections, quality issues,
  Redis priority notifications, durable worker jobs and provisional live state.
* Added bounded history ingestion, session-aware aggregation and integrity tests.
* Deferred indicators, scans, signals, backtests and ML per requested scope.

## Milestone 2 offline continuation

* Added deterministic EMA/RSI/MACD/ATR/ADX/VWAP/relative-volume calculations.
* Added immutable settings, known-at metadata, revision-aware repository reads
  and an offline JSON command.
* Validated formulas, prefix invariance, rejected inputs and correction timing.
* Live analysis and signals remain disabled pending market-data acceptance.
